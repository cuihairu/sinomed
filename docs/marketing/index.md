# Merchant Marketing Materials: Usage Guide

These are marketing copy templates for merchants. There is only one thing to do with them: replace the placeholders in 【】 with your own information, read through once and fix any sentence that does not match your situation, and the copy is ready to publish.

## Material list

| Material | File | Where to use |
| ---- | ---- | ---- |
| Grand-opening introduction | [article-opening](./article-opening) | Official-account article, published within a week before or after opening |
| Soft advertorial (health education) | [article-science](./article-science) | Official-account article, published regularly — builds goodwill without a hard sell |
| Promotional campaign | [article-promo](./article-promo) | Official-account article, for holiday / anniversary / member-day events |
| WeChat Moments short copy | [moments](./moments) | WeChat Moments, posted with images, as an everyday rhythm |

## Placeholder reference

All templates share the same set of placeholders. Before replacing them, make a checklist and go through them one by one:

| Placeholder | Replace with |
| ---- | ---- |
| 【商家名】 | The clinic's full name |
| 【地址】 | The full street address; adding a nearby landmark helps |
| 【电话】 | The front-desk phone number |
| 【预约方式】 | Phone / WeChat / mini-program booking entry |
| 【营业时间】 | e.g., 9:00–20:00 daily |
| 【医生姓名】 | The practicing doctor's real name |
| 【擅长方向】 | e.g., 脾胃调理 (digestive care), 颈肩腰腿痛 (neck, shoulder, lower back and leg pain) |
| 【活动内容】 | The specific offer — state quantities and deadlines clearly |
| 【活动截止】 | A concrete date; never write "end of the month" or "this week" |
| 【小程序码】 | The mini-program QR code image (downloadable from the backend) |

## Pre-publish checklist

1. **Zero placeholders left**: search the whole text for "【" — not a single one should remain.
2. **Concrete dates**: in campaign copy, write the deadline as "October 31", not "end of the month".
3. **Compliance**: no promises of therapeutic outcome. The templates only state care directions and service contents — if you added words like "根治" (guaranteed cure), "包好" (it will surely work), or "百分百" (100%), delete them.
4. **Banned-word check**: none of the following may appear anywhere — "自研" (self-developed), "自主研发" (independently developed), "行业领先" (industry-leading), "对标××" (benchmarking ××), "全网最低" (lowest on the internet), "独家秘方" (exclusive secret formula). These claims are either untrue or violate advertising law.
5. **Contact number reachable**: call the 【电话】 number once before publishing to confirm it is neither constantly busy nor out of service.
