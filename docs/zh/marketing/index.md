# 商家推广材料使用说明

这里是给商家用的推广文案模板。拿到手只需要做一件事：把【】里的占位符换成自己的信息，通读一遍改掉不合自己情况的句子，就可以发。

## 材料清单

| 材料 | 文件 | 用在哪 |
| ---- | ---- | ---- |
| 开业介绍 | [article-opening](./article-opening) | 公众号推文，开业前后一周内发 |
| 中医科普软广 | [article-science](./article-science) | 公众号推文，平时发，拉好感不硬卖 |
| 活动促销 | [article-promo](./article-promo) | 公众号推文，节庆/店庆/会员日活动 |
| 朋友圈短文案 | [moments](./moments) | 朋友圈，配图发，日常节奏 |

## 占位符对照

所有模板用同一套占位符，替换前先列一张清单逐个查：

| 占位符 | 换成 |
| ---- | ---- |
| 【商家名】 | 馆名全称 |
| 【地址】 | 详细地址，最好补一句"附近地标" |
| 【电话】 | 前台电话 |
| 【预约方式】 | 电话 / 微信 / 小程序入口 |
| 【营业时间】 | 例：每天 9:00–20:00 |
| 【医生姓名】 | 出诊医生实名 |
| 【擅长方向】 | 例：脾胃调理、颈肩腰腿痛 |
| 【活动内容】 | 具体优惠，写清楚数量和期限 |
| 【活动截止】 | 具体日期，别写"月底""本周" |
| 【小程序码】 | 小程序码图片（后台可下载） |

## 发布前自查

1. **占位符清零**：全文搜索"【"，一个都不该剩。
2. **日期具体**：活动类文案的截止日期写"10 月 31 日"，不写"月底"。
3. **资质合规**：不写疗效承诺。模板里只写调理方向和服务内容，"根治""包好""百分百"这类词自己加了要删掉。
4. **禁用词自查**：以下词一个都不出现——"自研""自主研发""行业领先""对标××""全网最低""独家秘方"。这些词要么不实，要么违反广告法。
5. **联系方式可接通**：发之前打一遍【电话】，确认占线或者换号了没。
