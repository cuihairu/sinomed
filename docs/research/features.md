# Feature List

> Organized by layer: general clinic essentials first, then TCM-specific items on their own. Each feature notes the reference source projects (per each project's actual README description) and Sinomed's current source-code status (per the actual implementation in `server/`); it serves as a checklist for future planning.

Legend — Sinomed status: **已实现 / implemented** (API and pages available) / **部分 / partial** (related fields or placeholders exist) / **未实现 / not implemented** (absent from the source code).

## 4. Sourcing Advice for Planning

- For the **business model**, reference Yukang first (highest overlap with a TCM clinic) and openhis-clinic (a closed loop of 5 clinic modules); both are covered in the [open-source project survey](/research/projects).
- Check licenses before **reusing code**: MIT/Apache allow relaxed reference; GPL-3.0 (the openhis family) is contagious; unlicensed projects (chinese_medicine_store_cos, his_mvp, etc.) may be consulted for ideas only — never copy code.
- Feature names and copy follow this repo's source code (patient / diagnosis / feedback / employee / service-card systems); avoid naming collisions with existing modules when introducing new ones.
