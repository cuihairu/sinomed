# Open-Source Icon Collection and Reference Table

> 🌐 [中文](./icons.md) · **This page is in English**

Clinic-scene icons all come from existing open-source icon libraries — no graphics were drawn from scratch. Checked into `web/src/assets/icons/`, 29 icons in total (16 primary + 8 alternate + 5 later additions).

- **Healthicons**: a healthcare-themed icon set. The icons themselves are released under **CC0 1.0** (public domain) — free for any use, no attribution, free to modify. 48×48 filled outline style.
- **Tabler Icons**: **MIT license** — free to use, modify, and distribute; just keep the copyright notice and license text when redistributing. 24×24 line stroke style, supports `currentColor` coloring.

All 24 direct links in this collection were verified to return HTTP 200 at intake, and the SVG file contents were spot-checked to confirm they are genuine icons.

## Source Notes

- Healthicons' actual repository is `resolvetosavelives/healthicons`; the root `LICENSE` (MIT) covers only the website source code. The icons themselves are CC0, as stated on the official site and in the README. Official site: <https://healthicons.org/>
- Tabler Icons is the `tabler/tabler-icons` repository, MIT licensed, <https://tabler.io/icons>

## Selection Notes (as-is record, not a visual sign-off)

- Neither library has a dedicated "acupuncture" icon: Tabler's `needle` is officially tagged as sewing/tailoring (a sewing needle) and is the visually closest existing open-source icon for a fine needle; the alternate Healthicons `syringe` (a syringe) is the substitute imagery.
- For the TCM scene, `medicine-mortar` (a mortar and pestle) is the closest existing icon in either library.
- Mixed-style note: Healthicons are 48×48 filled, Tabler are 24×24 stroked; the two can be mixed once the frontend applies unified coloring. If strict unification is needed, each library offers its own filled / outline variants.
