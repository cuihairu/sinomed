# Beauty / TCM Aesthetics — Industry Research (Chinese only)

> **This note exists only in Chinese.** Read the original: [美容护肤 / 中医美容 业态调研](/zh/research/beauty-salon-feature-survey)

**What it is.** Industry research on beauty-salon management systems, taken over from the former
`salon` repository in 2026-10-18. That repo has been merged into this one and is no longer
developed separately.

**Scope.** Skincare and TCM aesthetics — hair services excluded.

**Role.** It serves as the requirement reference for the salon-line extension
([Salon extension review](/design/salon-extension)). It does **not** change Sinomed's existing
single-store TCM clinic scope.

**Why there is no translation.** The note is a long-form, source-heavy survey — nine
category sections built on primary sources: regulation texts, Chinese beauty-industry SaaS
vendor pages and industry articles, plus a vendor interface gallery with screenshots. Its
value lies in the Chinese-market specifics (vendor names, regulation citations, and
explicit notes on Taiwan-market sources) rather than in the framing, so it was kept in
Chinese instead of translated. This short stub exists so the language switcher on the
Chinese page has a valid English target.

**Honesty conventions carried over from the original note.**

- Sources are given as links; any judgement that cannot be backed by a reliable source is
  marked "unverified".
- Vendor-promoted figures (conversion rates, recall rates and similar) are marked
  "vendor claim, unverified".
- Sources from Taiwan apply to the Taiwan market and are not to be read as mainland data.
